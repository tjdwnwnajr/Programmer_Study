#CS06 - 운영체제
## 1. 운영체제 학습 큰 그림

### 커널: 운영체제의 핵심기능을 담당하는 부품
핵심기능이란?
1.	자원할당 및 관리
2.	프로세스 및 스레드 관리

#### 자원할당 및 관리
- 01. CPU 관리 = CPU 스케줄링
운영체제는 실행 중인 모든 프로그램들이 합리적으로 CPU를 할당받도록 CPU할당순서, 사용시간을 결정한다.
	-우선순위/ 스케줄링 큐 / 선점형과 비선점형
	-CPU 스케줄링 알고리즘
	-리눅스 CPU 스케줄링

- 02. 메모리 관리 = 가상 메모리 기법
프로그램 실행 -> 메모리 적재 / 프로그램 종료 -> 메모리 삭제
	-물리주소와 논리주소
	-메모리 할당
	-페이징과 페이지 교체 알고리즘
- 03. 파일/디렉토리(폴더) 관리 = 파일시스템
보조기억장치 내 정보를 파일, 폴더로 관리하는 파일시스템이라는 프로그램을 이용
파일시스템은 커널의 내 프로그램
	-파일과 디렉토리
	-파일 시스템
- 04. 입출력장치 / 캐시 메모리 관리
장치드라이버, 하드웨어 인터럽트 서비스 루틴 제공 -> 입출력 관리
캐시메모리 일관성 유지 프로토콜 -> 캐시 메모리 관리

#### 프로세스 및 스레드 관리
- 프로세스 : 실행 중인 프로그램
- 스레드 : 프로세스를 이루는 실행 단위 (여러 개의 스레드가 동시 다발적으로 실행 가능)
	- 프로세스 스레드
	- 동기화와 교착 상태 해결 (실행 순서 제어, 자원 배분)

#### 운영체제(커널 포함)는 어떻게 메모리에 적재되어 있는가?

메모리 내 커널 영역 -운영체제 적재
메모리 내 사용자 영역 -여러 응용 프로그램 적재
- 운영체제 기능을 제공받기 위해서는 커널에 적재된 운영체제 코드가 필요함

#### 시스템 콜 : 운영체제의 서비스를 받기위한 수단(인터페이스)으로 호출가능한 함수 형태
종류
 
응용 프로그램 -> 시스템 콜 -> 소프트웨어 인터럽트 -> CPU커널 모드 전환 -> 운영체제 코드 실행 -> 결과 return -> CPU 사용자 모드 재전환
이중 모드/ 듀얼 모드 : 커널모드(운영체제 명령어 사용가능), 사용자 모드(운영체제 명령어 사용 불가)로 CPU모드를 구분지어 실행하는 것
cf) 프로세스 계층 구조
프로세스는 시스템 콜로 다른 프로세스를 생성 -> 운영체제는 이를 계층적으로 관리
부모 프로세스 : 새 프로세스를 생성한 프로세스
자식 프로세스 : 부모 프로세스에 의해 생성된 프로세스
