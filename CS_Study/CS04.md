#CS공부 -컴퓨터 구조

## 4. 핵심 부품 메모리
- 메인 메모리 : HW로 RAM을 이용 (Random access memory -임의접근 <-> 순차 접근)
	+ 특성 : 
	1. 휘발성 저장장치 
	2. 보조기억장치 : 비휘발성저장장치 필요
		+ 종류:
		1. DRAM(dynamic) : 저장된 data가 동적으로 점차 사라짐 -> 일정주기로 재활성화 필요 (소비 전력이 낮고 집적도가 높아 대용량 설계에 사용)
		2. SRAM(static) : 저장된 데이터가 변동되지 않지만 역시 전원이 공급되지 않으면 소실(속도가 높지만 가격이 빘가ㅗ 집적도가 낮아 캐시메모리에 사용)
		3. SDRAM(synchronous dynamic) : 클럭신호와 동기화된 발전된 RAM -클럭타이밍에 맞춰 CPU와 정보를 교환하여 송수신에 유리
		4. DDR SDRAM(double rate) : 대역폭이 SDRAM의 2배

### 메모리에 데이터를 저장하는 방식
일반적으로 CPU로부터 4/8바이트 = 워드 단위로 데이터를 받아서 4개/8개의 주소에 저장
- 바이트 저장 순서
	- 빅엔디안 : 낮은 번지의 주소에 상위 바이트부터 저장하는 방식 - 디버깅에 유리
	- 리틀엔디안 : 낮은 번지의 주소에 하위 바이트부터 저장하는 방식 - 메모리 값을 읽는 것은 불편하지만 수치 계산이 편리
MSB : 숫자 크기에 가장 큰 영향을 주는 비트 (가장 왼쪽 비트)
LSB  : 숫자 크기에 가장 작은 영향을 주는 비트 (가장 오른쪽 비트)

### 캐시메모리 : CPU 연산속도와 메모리 접근 속도 차이를 줄이기 위해 생긴 SRAM 기반의 저장장치 (cpu대기 시간을 감소)
크게 3가지 캐시 메모리 존재
코어 내부 : L1캐시, L2캐시
코어 외부 : L3캐시
멀티 코어 : 코어마다 L1,L2캐시 존재, L3캐시는 공유
분리형 캐시 : L1캐시를 분리하여 사용
L1I캐시 : 명령어만을 저장
L1D캐시 : 데이터만을 저장

- 캐시히트 : 캐시 메모리 예측/저장이 실제 CPU에 의해 사용되는 경우
- 캐시 미스 : 틀린 예측으로 CPU가 메모리로부터 필요한 데이터를 가져와야 하는 경우
- 캐시 적중률 : 히트 / (히트 + 미스) (85~95% 이상을 사용)

### 캐시메모리 저장하는 방식 (쓰기)
- 참조 지역성의 원리 : 원칙에 따라 가져올 Data를 결정한다.
1. 시간 지역성: CPU는 최근 접근 메모리에 재접근한다. ex)변수 -메모리에 저장된 후 자주 참조 됨
2. 공간 지역성: CPU는 접근한 메모리 근처에 접근한다. ex)배열 -메모리 상에 관련된 데이터를 일렬로 저장

### 캐시메모리 쓰기 정책과 일관성 (수정시 유의 사항)
캐시메모리에 적힌 데이터와 메모리 상의 데이터 일관성 유지가 중요

1. 즉시쓰기 : 캐시메모리와 메모리에 동시에 쓴다.
- 장점: 일관성 유지
- 단점: 쓰기 작업마다 메모리 참조로 시간이 소요

2. 지연쓰기 : 캐시 메모리만 수정 후 추후 수정된 데이터를 한 번에 메모리에 반영.
- 장점: 메모리 접근 횟수가 적어 속도가 빠름
- 단점: 일관성 깨질 위험이 존재

캐시된 데이터는 성능향상을 돕지만 데이터 간 불일치 위험을 신경써야함.
