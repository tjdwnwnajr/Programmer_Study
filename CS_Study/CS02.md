#CS 공부 -컴퓨터 구조

## 2. 컴퓨터가 이해하는 정보 (07-15)

### 2-1. DATA
- 비트  : 0 or 1 의 정보
- n bit : 2의 n승
- byte : 8bit -> 256개 정보
- 워드 : CPU가 한번에 처리할 수 있는 데이터의 크기 (32bit / 64bit)

#### 수 표현
- 정수: 2진수 or 16진수로 표현
- 실수: 정밀도의 한계가 존재한다.
1. 부동소수점 : 소수점이 고정되어 있지 않는다.
2진수 표현 : m X 2의 n승 으로 표현가능 n:소수점을 이동한 횟수(양수 -왼쪽, 음수 -오른쪽)
m과 n을 저장하는 방식 : IEEE 754
1. 32bit ->실수 표현
부호 1비트, 지수(n) 8비트, 가수(소수 부분 = m) 23비트
2. 64bit ->실수 표현
부호 1비트, 지수 11비트, 가수 52비트
부호비트 : 0(+), 1(-) 의미
가수: m=1.xxxx로 약속 따라서 1은 저장할 필요 X 따라서 xxxx만 저장
지수: 바이어스 값 (2^(k-1) -1)을 더해서 저장 k = 지수의 비트 수
ex) 32bit 저장, 1.1010111010101 x 2^6 /  k = 8bit 바이어스 = 127 따라서 지수는 133

* 오차가 생기는 이유
10진수 소수가 모두 2진수 소수 표현 1.m X 2^n 꼴로 표현될 때 무한히 많은 소수점이 필요하지만 저장공간은 한정적이기 때문

#### 문자 표현
- 문자집합 : 컴퓨터가 이해 가능한 문자 집합
- 인코딩 : 문자집합을 0,1 로 변환하는 과정
- 디코딩 : 0,1로 표현된 문자를 사람 문자로 변환하는 과정
- 코드 포인트: 인코딩에서 글자에 부여한 고유 값

##### 인코딩 방식
1. 아스키: 1byte 사용
1bit (오류 검출 패리티비트) + 7bit(표현 가능 수 = 128개)
A의 코드 포인트 : 65 (그대로 인코딩한 값으로 대응)

2. 한글 인코딩 EUC-KR : 2byte 사용 총 2350글자 가능
코드포인트: 4자리 16진수 (그대로 인코딩한 값으로 대응)

* 유니코드 : 다양한 언어, 특수문자까지 코드로 표현할 수 있는 통일된 문자집합
코드 포인트: 4자리 16진수 (이값을 다양한 방법으로 인코딩을 한다)
인코딩: utf-8, utf-16, utf-32 (뒤에 숫자에 따라 인코딩 된 결과의 길이가 길어진다)

3. base64: 64개의 아스키 문자로 변환하는 인코딩 -문자, 이진데이터 변환(문자보다는 이미지 데이터 등)
64진수 표현을 위해 6비트가 필요, 데이터를 6비트씩 나누어 문자로 변환
6비트로 나누어 떨어지지 않는 자리는 0으로 채워지는 패딩이 된다. 이는 =으로 인코딩

### 2-2.명령어
동작 +수행할 대상(데이터 or 데이터 위치)
연산코드 + 오퍼랜드
동작 = 연산코드, 수행할 대상 = 오퍼랜드/피연산자
if: 피연산자에 주소가 있을 경우 주소에 접근하는 추가적인 메모리 접근이 필요

#### 연산코드
- 1. 데이터 전송
- 2. 산술/논리 연산
- 3. 제어 흐름 변경
- 4. 입출력 제어

*스택: 메모리 안에 존재하는 영역 LIFO의 특징을 가짐

##### 기계어 : CPU가 이해할수 있도록 0,1로 표현한 명령어 <-> 단순 번역한 언어 (어셈블리어)
기계어 파일 = 실행파일
CPU에 따라 기계어 어셈블리어가 달라진다

#### 명령어 사이클 : CPU가 메모리 속 명령어를 실행하는 일정한 주기/흐름
- 명령어 과정
1. 인출 사이클 : 메모리 내 명령어를 CPU로 가져오는 단계
2. 간접 사이클 : 추가적인 메모리 접근이 필요한 경우 접근하는 단계
3. 실행 사이클 : 명령어를 처리하는 단계
4. 인터럽트 사이클 : 인터럽트 발생할 경우
