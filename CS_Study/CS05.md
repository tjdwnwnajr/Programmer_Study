#CS공부 -컴퓨터 구조

## 5. 핵심 부품 보조기억장치 +입출력 장치 = 주변장치

### 보조기억장치 : 보관할 프로그램을 저장하는 장치
종류:
+ 1. 하드디스크 드라이브 (HDD)
+ 2. 플래시메모리 가반 저장장치 (SSD, SD카드, USB메모리 등)

하드디스크 : 저장(플래터) +회전(스핀들) +읽기(헤드)로 구성

RAID : 데이터를 안전하고 안정적으로 제공하기 위한 기법으로 여러개의 독립적인 보조기억장치를 하나의 보조기억장치로 사용하는 기술

RAID구성 방법 = RAID 레벨

#### RAID0: 데이터를 단순하게 나누어 분산 저장하는 방식
스트라입 : 줄무늬처럼 분산되어 저장된 데이터를 의미
스트라이핑 : 분산하여 저장하는 동작 자체를 의미
+ 장점: 빠른 입출력속도
+ 단점: 일부 디스크 고장 시 다른 디스크에 있는 데이터또한 온전하지 않을 수 있음 = 저장된정보의 안전성이 부족

#### RAID1 : 완전한 복사본을 만들어 저장하는 방식
미러링: 완전히 복사하여 다른 디스크에 저장
+ 장점: 복구가 간단하고 안전성이 높다
+ 단점: 복사본 크기만큼 사용가능한 용량이 적어짐, 원본 및 복사본에 모두 데이터를 입력해야되기 때문에 쓰기 작업이 느림

#### RAID4 :  패리티비트(오류검출용정보)를 저장하는 디스크를 따로두는 방식 =패리티비트 전용 디스크
+ 장점: RAID1에 비해 적은 하드디스크로 안전성 확보, 
+ 단점: 패리티비트 저장 장치에 병목 현상 발생 가능 ex) a1데이터,a2데이터 접근 시 패리티a데이터에 접근을 하여 디스크4에 병목

#### RAID5: 패리티를 분산하여 저장
+ 장점: RAID4의 단점 보완

#### RAID6 : 서로 다른 2개의 패리티를 두는 방식
+ 장점: 안전성이 높다
+ 단점: 저장공간이 그만큼 줄어든다. 정보를 저장할 때마다 함께 패리티 2개를 저장하므로 쓰기속도가 RAID5보다 더 느리다

#### Nested RAID
+ RAID10 = RAID0 +RAID1 : 분산저장 +복사본 저장
+ RAID50 = RAID0 +RAID5

### 입출력 장치
+ 장치 컨트롤러 : CPU와 입출력 장치 사이에 통신을 중개하는 하드웨어
+ 장치 드라이버 : 장치 컨트롤러가 컴퓨터와 정보를 주고 받도록 해주는 프로그램

#### 입출력 기법 4종류
+ 1. 프로그램 입출력 :  프로그램 속 명령어로 입출력을 실행
	+ 1.고립형 입출력: 메모리를 위한 주소 공간과 입출력장치를 위한 주소 공간이 별도로 분리되어있음
	+ 2.메모리 맵 입출력: 메모리를 위한 주소 공간과 입출력장치를 위한 주소 공간이 별도로 분리되지 않음
	주소공간이 별도일 경우 입출력 장치만을 위한 명령어가 별도로 존재하고 메모리를 위한 명령어가 별도로 존재한다.

+ 2. 인터럽트 기반 입출력 : 다중 인터럽트를 통한 입출력 실행
cf) 인터럽트는 여러 장치로부터 동시다발적으로 발생한다.
if) CPU가 플래그 레지스터 속 인터럽트 비트를 비활성화한 채 인터럽트를 처리할 경우
-> NMI(막을 수 없는 인터럽트)를 제외하고는 순차적으로 인터럽트를 처리
but) NMI가 있거나 인터럽트 비트가 활성화된 경우
-> 우선순위에 따라 현재 진행중인 ISR을 멈추고 다른 인터럽트 처리

##### 어떻게 우선순위를 판단하는가?

프로그래머블 인터럽트 컨트롤러(PIC -하드웨어)
여러개의 발을 가진 장치로 인터럽트 요청신호를 입력으로 받고 판단하여 CPU나 다른 PIC에 처리해야할 인터럽트를 출력
+ 주로 계층적으로 구성

+ 3. PMA 입출력
기존의 방식의 공통점: CPU가 입출력장치와 메모리 간의 데이터 이동을 주도하며 이동하는 데이터는 모두 CPU를 거쳐야 함
문제점: 다 CPU를 거치기에 CPU병목 현상으로 부담이 됨
따라서 CPU를 거치지 않고 메모리와 입출력 장치가 서로 직접 상호작용하는 기법

	+ CPU --시스템버스--DMA 컨트롤러--메모리
	+ 입출력버스--장치컨트롤러1-입출력장치1

과정
1. CPU ->입출력장치 주소, 수행연산, 연산할 메모리 주소 등 입출력 작업 명령 -> DMA컨트롤러
2. DMA컨트롤러가 CPU대신 상호작용 -> 입출력 작업 수행 -> 필요시 메모리 접근
3. 입출력 작업 완료->DMA 컨트롤러->작업 종료 인터럽트->CPU
장점: CPU의 부담이 적다

cf) 사이클 스틸링: DMA컨트롤러가 시스템 버스를 사용하는 양상을 의미
버스=공용자원= 두장치가 동시에 하나의 버스를 이용할 수 없다
즉 DMA컨트롤러와 CPU가 동시에 시스템 버스를 사용할 수 없으며  따라서 CPU가 사용하지 않을 때 조금씩 사용하거나 CPU가 시스템 버스를 양보하는 양상

##### 입출력 버스 종류
PCIe : PCI의 발전된 형태
+ 특징:
1. 버전에 따라 최대 속도가 높아진다.
2. 여러레인을 이용하여 정보를 주고 받는다
++ 레인: 버스를 통해 정보를 송수신하는 단위=길의개수
ex)PCIe 4.0 x 4 = 4.0버전 4개의 레인
최대속도 = 버전 최대속도 x 레인 수
